## Context

Now I my opinion using cli to monitering database is a bit too hard, I want some UI to manage database for learning.

### Option 1: phpMyadmin

__Pros__:
- Have UI on website.
- Can create database and `Preview SQL` feature

__Cons__:
- A bit cumbersome to setup with our reverse proxy.

### Option 2: mysql cli

__Pros__:
- Learn and debug with real database client.

__Cons__:
- Ugly.
- Hard to start.

## Decision

__Option 1: phpMyadmin__
