## Context

Subject said you have to use this TechStack: php(or other language in standard php library), Html, CSS, Javascript without framework
except CSS framework doesn’t need forbidden JavaScript;

### Option 1: VanillaJS

__Pros__:
- Have low risk to summit project.
- Easy to understand how website work, for me who come from low level programming.

__Cons__:
- hard to develop, route, and make component.

### Option 2: ReactJs

__Pros__:
- Easy to develop, routing, and make beautiful webside.

__Cons__:
- Have hight risk to summit, Because ReactJs have CSS module managed and create by javascript,
Maybe forbidden if someone know how inside ReactJs lib work.

## Decision

Selected: __Option 1: VanillaJS__.
